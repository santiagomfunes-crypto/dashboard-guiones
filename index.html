Para empezar, configura las credenciales de Supabase en el archivo dashboard.html.

Busca estas lineas al inicio del <script>:

const SUPABASE_URL = 'tu-url';
const SUPABASE_KEY = 'tu-anon-key';

Ambos valores se encuentran en el panel de Supabase, seccion Settings > API.
